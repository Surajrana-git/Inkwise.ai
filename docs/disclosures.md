# Disclosures

Kept up to date by every member during the build.

## AI models and APIs
- **Google Gemini API** (free tier) reviews copy, reads the text and logo in campaign images, and drafts clearer
  guideline wording. Free-tier prompts may be used by Google to improve its products, so the demo uses synthetic data
  only and masks personal data before every call. Production setting: paid tier.
- **Models:** the primary model is set with `GEMINI_MODEL` (default `gemini-flash-latest`); when it is busy or over
  quota the engine falls back to `gemini-3.6-flash`, `gemini-3.5-flash-lite` and `gemini-3.1-flash-lite`
  (override with `GEMINI_FALLBACK_MODELS`). The model that answered is recorded with each review.
- **Search:** keyword (BM25) search over the brand kit by default. Gemini embeddings with ChromaDB are optional
  (`INKWISE_SEMANTIC=1`).

## Data
- **Lumora brand kit**: fictional, written by the team (guidelines, facts with owners and expiry dates, glossary,
  image rules and palette).
- **Evaluation set**: synthetic samples generated with Adaption Labs, labels checked by hand
  (`eval/build_dataset.py`; raw drafts in `eval/raw/` were not used for scoring).
- **Fact-freshness test group** (`eval/fact_cases.jsonl`): written by the team.
- **Images**: the sample banner (`app/assets/sample_banner.png`) is drawn in code with Pillow, using the team's own
  logo. The sign-in background photos were AI-generated by the team.
